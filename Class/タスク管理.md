# タスク管理

「次に何をするか」をチェックボックスで管理します。小さなタスクはデイリーノートに直接書き、背景・完了条件・関連資料を持つタスクだけ `Template/Task.md` から専用ノートを作ります。

> [!cards]
> ```meta-bind-button
> style: primary
> label: タスクノートを追加
> id: create-task-note
> action:
>   type: templaterCreateNote
>   templateFile: "Template/Task.md"
>   folderPath: "Pages"
> ```

## 入力例

```markdown
- [ ] 論文の図3を再確認する 🔼 📅 2026-09-10 #task/research
- [/] Zoteroのタグを整理する 📅 2026-09-08 #task/library
- [x] Obsidianの初期設定を確認した ✅ 2026-09-06
```

- `[ ]`: 未着手、`[/]`: 実行中、`[x]`: 完了、`[-]`: 中止
- `📅`: 期限、`⏳`: 着手予定日、`🔼`: 高優先度
- タスクの本文をクリックして Tasks の編集画面を開くと、日付や繰り返しを安全に設定できます。
