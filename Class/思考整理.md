# 思考整理

結論が出ていない問いを、事実・解釈・選択肢・判断に分けて整理します。図で広げたい場合は [[思考整理テンプレート.canvas]] を複製して使います。

## 考え途中

```dataview
TABLE WITHOUT ID file.link AS テーマ, status AS 状態, created AS 作成日, file.mtime AS 更新
FROM #thinking
WHERE kind = "thinking" AND status != "decided" AND status != "archived"
SORT file.mtime DESC
```

## 判断済み

```dataview
TABLE WITHOUT ID file.link AS テーマ, created AS 作成日, file.mtime AS 更新
FROM #thinking
WHERE kind = "thinking" AND status = "decided"
SORT file.mtime DESC
```

## 整理の順番

1. 問いを1文にする。
2. 確認できた事実と、自分の解釈・仮説を混ぜずに書く。
3. 選択肢と評価軸を並べる。
4. 現時点の判断と、次に確かめることを残す。
5. 行動が決まったらチェックボックスのタスクへ変換する。
