# スケジュール管理

「いつ時間を使うか」が決まっているものを管理します。締切はタスクの期限、会議・通院・集中作業など開始時刻を確保するものは予定として分けます。

> [!tip] 2つのカレンダー
> - 右サイドバーの **Calendar**: 月全体を見ながら、日付をクリックして `Daily/` のデイリーノートを開く・作るための入口です。週は月曜日から始まります。
> - このページの **カレンダー**: `schedule` タグを持つ予定ノートを日付上に表示します。
>
> Calendarで日付を選ぶと、既存の `Template/Daily.md` を使ってその日のノートが作成されます。

> [!cards]
> ```meta-bind-button
> style: primary
> label: 予定を追加
> id: create-schedule-note
> action:
>   type: templaterCreateNote
>   templateFile: "Template/Schedule.md"
>   folderPath: "Pages"
> ```

## 今後の予定

```dataview
TABLE WITHOUT ID file.link AS 予定, scheduled AS 日付, start AS 開始, end AS 終了, status AS 状態
FROM #schedule
WHERE kind = "schedule" AND scheduled >= date(today) AND status != "cancelled"
SORT scheduled ASC, start ASC
```

## カレンダー

```dataview
CALENDAR scheduled
FROM #schedule
WHERE kind = "schedule" AND status != "cancelled"
```

カレンダー上の日付を選び、その日の計画・実績を開きたい場合は、右サイドバーの Calendar を使います。予定名を日付上で確認したい場合は、上の予定カレンダーを使います。

## 使い分け

| 記録したいこと | 使うもの | 例 |
| --- | --- | --- |
| 期限までに終える | タスクの `📅` | 9月10日までに資料を読む |
| その日に着手する | タスクの `⏳` | 9月8日にレビューを始める |
| 時間を確保する | 予定ノート | 14:00〜15:00 会議 |
| 日々の計画と実績 | デイリーノート | 今日の予定、持ち越し、気づき |
