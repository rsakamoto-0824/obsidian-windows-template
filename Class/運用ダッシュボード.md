## 今日の予定

```dataview
TABLE WITHOUT ID file.link AS 予定, start AS 開始, end AS 終了, status AS 状態
FROM #schedule
WHERE kind = "schedule" AND scheduled = date(today)
SORT start ASC
```

## 最近の思考とメモ

```dataview
TABLE WITHOUT ID file.link AS ノート, kind AS 種類, status AS 状態, file.mtime AS 更新
FROM (#thinking OR #memo)
SORT file.mtime DESC
LIMIT 8
```

## 運用のリズム

- 朝: 当日のデイリーノートを開き、予定と今日やるタスクを確認する。
- 日中: 行動が必要ならタスク、時刻が決まっているなら予定、考えを深めるなら思考整理、再利用する情報なら備忘録として記録する。
- 夕方: 完了チェック、持ち越し、次の一手をデイリーノートに残す。
- 週1回: [[タスク管理]] の未整理・期限超過と、[[思考整理]] の考え途中を見直す。
