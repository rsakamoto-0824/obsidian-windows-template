# 備忘録

再利用したい手順、設定、気づき、問い合わせ先などを短く残します。1ノート1テーマにすると、検索・リンク・AIによる再整理がしやすくなります。

> [!cards]
> ```meta-bind-button
> style: primary
> label: 備忘録を追加
> id: create-memo-note
> action:
>   type: templaterCreateNote
>   templateFile: "Template/Memo.md"
>   folderPath: "Pages"
> ```

## 最近の備忘録

```dataview
TABLE WITHOUT ID file.link AS メモ, status AS 状態, created AS 作成日, file.mtime AS 更新
FROM #memo
WHERE kind = "memo"
SORT file.mtime DESC
LIMIT 30
```

## 残し方

- タイトルだけで内容が推測できるようにする。
- 冒頭の「要点」に、未来の自分が最初に知りたい結論を書く。
- 元資料がある場合は「出典」にURL、Zoteroリンク、またはVault内リンクを残す。
- 分野をまたぐ場合もフォルダは増やさず、`topic/...` タグを追加する。
- パスワード、回復コード、秘密鍵は書かない。
